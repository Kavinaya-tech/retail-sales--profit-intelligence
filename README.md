# Retail Sales & Profit Intelligence

## Project Overview
This project analyzes retail sales data to understand sales performance, profitability, product categories, regional performance, and the relationship between discounts and profit.

## Business Objectives
- Measure total sales, total profit, and profit margin.
- Identify profitable and low-profit product sub-categories.
- Compare performance across categories and regions.
- Analyze the relationship between discounts and profit.
- Provide data-driven business recommendations.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Google Colab

## Project Workflow
1. Load and explore the dataset.
2. Inspect data quality.
3. Remove duplicate records and standardize column names and text.
4. Calculate key business metrics.
5. Analyze category, sub-category, and regional performance.
6. Investigate discounts and profitability.
7. Create visualizations and business recommendations.
8. Export cleaned data and analysis reports.

## Key Performance Indicators
- Total Sales
- Total Profit
- Profit Margin
- Total Quantity Sold
- Number of Records Analyzed

## Project Outputs
- `Retail_Sales_Intelligence.ipynb`
- `retail_sales_cleaned.csv`
- `category_performance.csv`
- `region_performance.csv`
- `subcategory_performance.csv`

## Limitations
The dataset used in this project does not include order IDs or order dates. Therefore, unique order counts and monthly sales trends are not analyzed. A relationship between discounts and profit does not necessarily prove causation.

## Conclusion
This project demonstrates practical skills in data cleaning, exploratory data analysis, KPI calculation, data visualization, and business insight generation using Python.
